# Face Recognition Unity

This project was made to experiment with augmented reality on Unity ARFoundation with an obj-c plugin for handling face detection using Google's MLKit.

The app was tested on an iPhone 11 Pro (A13 Bionic) and consumed quite a bit of battery and it used approximately 500MB of memory while achieving constant 30fps at 80% - 130% CPU usage most of the time with some spikes nearing 200%. The A13 chip has 4 efficiency cores and 2 performance cores meaning that the maximum CPU usage is 600%
